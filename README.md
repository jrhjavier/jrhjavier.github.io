# Resinapsis

## Descripción

**Resinapsis** es un sitio web desarrollado con fines académicos como parte del **Trabajo Fin de Grado en Enfermería**, centrado en la creación de un centro de rehabilitación para personas jóvenes con secuelas derivadas de un accidente cerebrovascular (ACV).

El objetivo de esta página es presentar de forma clara y accesible la propuesta del proyecto, su misión, los servicios planteados y la información complementaria relacionada con la iniciativa.

## Estructura del proyecto
```text
/
├── assets/
│   └── Imágenes y recursos gráficos utilizados en la web
├── css/
│   └── styles.css
├── pages/
│   ├── aviso-legal.html
│   └── politica-privacidad.html
├── index.html
└── README.md
```


### Contenido de las carpetas

- **assets/**: contiene las imágenes y recursos visuales empleados en el sitio web.
- **css/**: incluye la hoja de estilos principal (`styles.css`) encargada del diseño y la apariencia de la página.
- **pages/**: alberga las páginas informativas y legales:
  - `aviso-legal.html`
  - `politica-privacidad.html`
- **index.html**: página principal que contiene el contenido y la estructura general del sitio web.

## Tecnologías utilizadas

- HTML5
- CSS3

## Finalidad académica

Este proyecto ha sido desarrollado exclusivamente con fines educativos y académicos en el contexto de un Trabajo Fin de Grado, sin ánimo de lucro ni finalidad comercial.
